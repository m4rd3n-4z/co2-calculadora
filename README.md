# 🧮 Calculadora CO2

Calcula emissões de gás carbônico e emite os valores em créditos de carbono levando em consideração a distância entre cidades brasileiras. 

## Como usar
1. Abra index.html
2. selecione as cidades
3. selecione o tipo de transporte
4. veja o resultado. 

Ex. Para ir de Porto Alegre a Belém de carro, 797,7Kg de CO2 serão lançados na atmosfera, Levando-se em consideração o preço de R$ 100,00 a tonelada de CO2 em Créditos de Carbono, o custo seria de R$79,77.
